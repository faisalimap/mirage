What is Mirage?

Chat apps like Instagram, WhatsApp and X read a link's title and description and show them as a preview card. Mirage lets you choose exactly what that card says, then gives you a short link on mrg.qd.je.

Anyone who opens the link sees a plain 404 Not Found page. The preview is the only thing it is made to show.

Why does it open as a 404?

The page exists only to carry preview text. It has no content, no scripts, no tracking and no forms, so there is nothing to find behind the link. The 404 look keeps it clean and makes it obvious the page is not a real site.

Behind the scenes it is served with a normal success status so chat apps will read the preview. People just see the 404.

How it works

  1. You enter a title and description and pass a captcha.
  2. A server checks the text and creates a page with a random 6 to 7 character slug.
  3. You get mrg.qd.je/slug. Paste it into any chat to see the preview.
  4. The page is deleted automatically after 3 days.

FAQ

Can I edit a link later?

No. Chat apps cache previews, so an edit would not show. Create a new link instead.

Does it store my data?

Only the title and description you enter, inside the link page, for 3 days. Nothing else is kept about you.

Can I add an image?

Not yet. Previews are text only.

Why is there a captcha?

To stop bots from flooding the service with links.
